## Project

Single-page personal portfolio for Erick Fierro (COBOL/Mainframe developer), built with Next.js 15 (App Router), TypeScript, and Tailwind CSS v4. Statically exported and deployed to GitHub Pages. There is no backend — all content lives in `app/page.tsx` and `lib/i18n.ts`.

## Commands

```bash
pnpm install    # Install dependencies
pnpm dev        # Dev server at http://localhost:3000
pnpm build      # Static export to /out (required by next.config.mjs: output: "export")
pnpm lint       # next lint
```

There is no test suite configured. `next.config.mjs` sets `eslint.ignoreDuringBuilds: true` and `typescript.ignoreBuildErrors: true`, so `pnpm build` will succeed even with lint/type errors — run `pnpm lint` and `tsc --noEmit` explicitly to catch issues.

## Architecture

- **Everything is one page.** `app/page.tsx` renders the entire site (intro/work/projects/connect sections) as a single client component (`"use client"`). There is no routing beyond this page plus `app/robots.ts` and `app/sitemap.ts`.
- **i18n**: `lib/i18n.ts` exports a `translations` object keyed by `Locale` (`"en" | "es"`) containing all copy, including work history (`jobs`) and fallback project cards (`projects`). `components/language-context.tsx` provides `LanguageProvider`/`useLanguage()`, persisting the chosen locale to `localStorage` (`locale` key) and syncing `document.documentElement.lang`. To edit site copy or add a language, work in `lib/i18n.ts` — do not hardcode strings in `page.tsx`.
- **Dark mode is hand-rolled, not next-themes.** `app/page.tsx` manages `isDark` state itself, toggles the `dark` class on `document.documentElement`, and persists to `localStorage` under the `theme` key. `components/theme-provider.tsx` wraps `next-themes` but is currently unused/unwired — don't assume it's active.
- **Featured projects are fetched, not hardcoded.** On mount, `page.tsx` fetches `/github-repos.json` (generated into `public/github-repos.json`) and renders those as project cards if present, falling back to the static `t.projects` list from `lib/i18n.ts` otherwise. `public/github-repos.json` is regenerated by the `Update Featured Projects` GitHub Action (`.github/workflows/update-projects.yml`), which pulls repos tagged `featured` from the GitHub API and commits the result — don't hand-edit it expecting it to persist.
- **shadcn/ui is configured but not scaffolded.** `components.json` points aliases at `@/components/ui` and `@/hooks`, and most Radix packages are in `package.json`, but neither directory exists yet — components must be added via the shadcn CLI (or manually) before those aliases resolve.
- **Styling**: Tailwind v4 with CSS-variable-based theming in `app/globals.css` (`:root` / `.dark` blocks feeding a `@theme inline` block). No `tailwind.config` file — v4 is configured entirely through CSS.
- **Deployment**: `.github/workflows/nextjs.yml` builds and deploys `/out` to GitHub Pages on push to `main`. `output: "export"` means no server-side features (API routes, ISR, image optimization) are usable — `images.unoptimized: true` is set accordingly.
